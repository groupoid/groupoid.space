Теорія мов програмування

Робоча програма навчальної дисципліни (відповідно до вимог МОН України).
Документ містить мету, результати навчання, структуру змісту, систему оцінювання та літературу.

Код курсу: КА-121-06

Кафедра: Кафедра мовного забезпечення

Кількість кредитів ECTS: 6 (180 годин)

Рівень: Бакалавр / Магістр

Мета та завдання

Вивчення теорії мов програмування через ієрархію формальних систем Groupoid Infinity (homotopy.dev / 5ht.co): від чистих типових систем до модальної гомотопічної теорії типів. Курс демонструє, як конструктивні засади (MLTT, CIC, HTS) реалізуються в мінімальних перевірячах типів і служать основою для формальної математики.

Результати навчання

  • Пояснювати ієрархію систем: Henk → Frank → Christine → Per → Anders → Dan / Urs.
  • Розрізняти PTS, CoC, CIC, MLTT-80 та модальну HoTT.
  • Розуміти роль індуктивних типів, ідентифікаційних типів, кубічних примітивів та модальностей.
  • Аналізувати мінімальні реалізації перевірячів типів та їх метатеоретичні властивості (нормалізація, канонічність).
  • Застосовувати формальні системи для простих доведень та формалізацій.

Структура курсу (модулі)

  1. Вступ. Чисті типові системи та λ-куб. Henk (PTS / CoC∞)
  2. Індуктивні конструкції. Frank (CoC + CIC)
  3. Загальна індукція та рівність. Christine (CIC + Fix / Id)
  4. Інтуїціоністська теорія типів. Per (мінімальна MLTT-80 / CCHM)
  5. Модальна гомотопічна теорія типів. Anders (MLTT + HTS + кубічні примітиви + модальності)
  6. Сімпліціальні розширення. Dan (∞-HoTT / GAP / simplicial)
  7. Когезивні модальності. Urs (♭, ♯, ℑ — flat, sharp, infinitesimal)
  8. Порівняння систем, екстракція, практична формалізація
  9. Практична лабораторна: робота з Anders / Per / Henk

Система оцінювання (100 балів)

  • Поточний контроль (лабораторні, формалізації, рев’ю): 40 балів
  • Модульні контрольні роботи (2): 20 балів
  • Підсумковий іспит / захист проєкту (формалізація в одній із систем): 40 балів

Шкала: 90–100 — відмінно; 75–89 — добре; 60–74 — задовільно; <60 — незадовільно.

Рекомендована література

  • homotopy.dev — Anders Modal HTS та пов’язані системи.
  • 5ht.co/cv/ та groupoid.space (Volumes I–III) — статті про Henk, Frank, Per, Anders, Urs тощо.
  • Документація: henk.groupoid.space, frank.groupoid.space, per.groupoid.space, anders.groupoid.space.
  • Barendregt, Coquand, Martin-Löf, Voevodsky — класичні джерела PTS, CoC, MLTT, HTS.
  • Матеріали Groupoid Infinity / Namdak Tonpa.
