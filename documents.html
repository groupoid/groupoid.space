2. Статут (розширені основні положення)

СТАТУТ
Приватного закладу вищої освіти
«Інститут Формальної Математики»

Розділ 1. Загальні положення
1.1. Інститут є юридичною особою приватного права, закладом вищої освіти типу «інститут».
1.2. Основний вид діяльності — освітня діяльність на рівнях вищої освіти (бакалавр, магістр, доктор філософії) та наукова діяльність у галузі формальної математики, теоретичної інформатики та суміжних областях.
1.3. Інститут діє на принципах автономії відповідно до Закону України «Про вищу освіту».

Розділ 2. Структура
2.1. Структура Інституту: два факультети (Факультет прикладної математики, Факультет чистої математики) та п’ять кафедр.
2.2. Для приватних ЗВО структура, склад органів управління та порядок їх формування визначаються цим Статутом без обов’язкового дотримання всіх кількісних вимог статті 33 Закону для державних закладів.
2.3. Кафедри є базовими структурними підрозділами.

Розділ 3. Органи управління
- Засновники (загальні збори)
- Наглядова рада
- Ректор
- Вчена рада
- Студентське самоврядування (після набору студентів)

Розділ 4. Освітня та наукова діяльність
4.1. Інститут провадить освітню діяльність на підставі ліцензії МОН.
4.2. Наукова діяльність зосереджена на формальній верифікації, гомотопічній теорії типів, категорійній логіці тощо.

Повний текст статуту (20–40 сторінок) затверджується засновниками і реєструється.

3. Інші установчі та організаційні документи

  • Довідка про освітні програми Інституту (для МОН) — зведена інформація про всі п’ять освітніх програм.
  • Освітня програма «Формальна філософія та математика» — Кафедра формальної філософії (магістерський рівень).
  • Освітня програма «Формальні мови програмування» — Кафедра мовного забезпечення.
  • Освітня програма «Прикладна математика» — Кафедра прикладної математики.
  • Освітня програма «Теоретична інформатика» — Кафедра теоретичної інформатики.
  • Освітня програма «Чиста математика» — Кафедра чистої математики.
  • Положення про кафедри — детальний опис завдань, структури, прав завідувача та організації роботи п’яти кафедр.
  • Концепція освітньої діяльності — документ для ліцензування (рівні освіти, спеціальності, кадрове та матеріальне забезпечення, система якості).
  • Протокол загальних зборів засновників — про затвердження статуту, обрання органів.
  • Наказ ректора № 1 — про початок діяльності, затвердження структури та штатного розпису.
  • Положення про вчену раду.
  • Штатний розпис — з 5 докторами наук на основних місцях роботи.
  • Документи на приміщення — договір оренди / свідоцтво про власність (мін. 2000 м² навчальних площ).

4. Державна реєстрація

Реєстрація в Єдиному державному реєстрі юридичних осіб через ЦНАП або портал «Дія». Основний КВЕД: 85.42 «Вища освіта». Додаткові: наукові дослідження (72.19).

5. Підготовка до ліцензування

Після реєстрації — формування пакету для МОН (заява через ЄДЕБО, відомості про кадри, матеріальну базу, концепція). Див. розділ «Ліцензування МОН».
